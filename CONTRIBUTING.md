# Contributing

Thanks for considering contributing to this set! Here is how you can create a new project if you need help, assuming you have installed the necessary dependencies. [Click here](README.md#1-install-the-necessary-dependencies) to learn how.

## Creating a project

1. Open the command palette (`Ctrl + Shift + P`) and select `ESP-IDF: New Project`.
2. Choose the template named `sample_project` and create the project.
